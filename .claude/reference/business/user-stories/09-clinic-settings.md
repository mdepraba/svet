# User Stories — Clinic Settings

Covers clinic-wide configuration that doesn't belong to any single owner, patient, product, or
visit.

- As an **Admin**, I want to set the clinic's name, address, and contact details once, so they
  can be reused wherever the clinic's identity needs to appear (e.g. on invoices).
- As an **Admin**, I want to configure the invoice numbering format, so invoice numbers follow the
  clinic's own convention consistently.
- As an **Admin**, I want to update a clinic setting when circumstances change (e.g. the clinic
  moves address), without needing to touch any other part of the system.
- As an **Admin**, I want each setting to be uniquely named, so there's never ambiguity about
  which configuration value is being used.
